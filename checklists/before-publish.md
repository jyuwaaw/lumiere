# 发布前检查

- [ ] 素材许可逐条核对（打开每条素材页面看许可）：
  - CC0 不用署名
  - CC BY 必须写：作品名、作者、许可类型、原始链接，并注明“经切片、混音处理”
  - Mixkit 不要求署名
- [ ] 致敬或二创：写明原作者和原作链接
- [ ] 片中虚构的产品、品牌注明“虚构”
- [ ] 涉及数学或科学结论：写清验证到了什么程度，不夸大成“证明”
- [ ] 选好封面帧（这次用的是瘫坐镜头：闹钟 0:00，窗外烟花）
- [ ] B 站：标题、简介（含署名）、标签
- [ ] Twitter：线程每条不超过 280 字符，最后一条放署名和 B 站链接；视频上传 1080p（4K 太大）
