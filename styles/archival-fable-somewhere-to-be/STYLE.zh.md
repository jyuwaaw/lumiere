# 档案寓言（archival-fable · somewhere to be）

[English](STYLE.md) | **中文**

参照：Paradigm 的发布片（x.com/thescottfan/status/2119863088795001001）。
这部片：《Somewhere to Be》，CoreSpeed 的品牌片，103.5 秒，1920×1080 和 4K，24 fps，v2.3（2026-11-24）。

用档案素材讲一个寓言：铜版画和褪色的 16mm 胶片，耳语般的童话旁白，产品只在最后几秒出现。适合产品能回答一个观众本来就有感的问题的品牌片。

## 关键词

- **形式**：三幕寓言（一个有问题的世界、转折、答案）；16:9 画面里套 4:3 画框；静帧用 Ken Burns 推拉，配短的图生视频片段；越接近高潮硬切越快。
- **质感**：19 世纪铜版画加双色调；70 年代 16mm Ektachrome 画面，带颗粒、片门晃动、闪烁、光晕和灰尘；星图；每个镜头里都有一个发着柔光的小光球，代表“心智”。
- **故事**：
  1. 什么都能回答的心智，每天早上在空屋里醒来，没有记忆，也没有钥匙。
  2. 人们成了它们的看守，每天把同一个故事再讲一遍。
  3. 心智越来越多，人们开始害怕：门上了闩，每扇窗都派人盯着。
  4. 硬切黑场。
  5. 有人不再问心智有多聪明，而是问它们该住在哪。
  6. 答案里的每个画面对应产品的一项真实能力（会记事的房间、用你自己钥匙开的门、够得着你机器的手、叫醒它们的钟、开门前先问你的门卫）。
  7. 恐惧段的一个画面得到回应（锁链 → 挽具）；画面淡到黑，logo 单独出现。
- **灵魂**：**答案里的每个画面都是产品真有的能力**，恐惧也是真的。比喻要是对应不到任何已经上线的东西，就删掉。品牌只在最后出现，由 logo 承担，不靠念出名字。

## 情绪

谁的视角？照看心智的那些人。观众应该先惊奇，再疲惫，再害怕，最后得到一份挣来的释然。

| 段落 | 时间（秒） | 感受 | 配乐方向 |
|---|---|---|---|
| 惊奇 | 0–14 | 温柔、神奇、安静 | 钢片琴、八音盒、闷音钢琴、轻柔的高音弦乐 |
| 日常 | 14–31.6 | 疲惫、重复 | 像钟一样的拨弦固定音型，100 bpm，慢慢变强 |
| 恐惧 | 31.6–53.6 | 焦虑、无休止 | 120 bpm 的多层弦乐固定音型、低音铜管、太鼓般的重击、谢泼德音，结束在最响的一击上 |
| 黑场 | 53.6–55.2 | 一脚踩空 | 只剩那一击的混响尾音 |
| 转折 | 55.2–65 | 脆弱的希望 | 独奏闷音钢琴，单音，留很多空 |
| 上扬到高潮 | 65–92 | 温暖、推进、狂喜 | 钢琴琶音、温暖的弦乐，然后全编制管弦乐 |
| 落定 | 92–103.5 | 平静、到家了 | 一个长长的持续和弦，随 logo 一起淡出 |

## 镜头语法（103.5 秒）

| 时间（秒） | 镜头 |
|---|---|
| 0–14 | 铜版画和胶片：穹顶图书馆里的光球，黎明时空屋地板上的光球，被擦干净的石板，一条没有把手的门廊 |
| 14–31.6 | 日常，跟着钟点剪：围着玻璃罩里光球的人群、飞转的钟、读同一本书的手、从小窗递进去的钥匙、在满墙钥匙前睡着的看守、门边守夜的人。滴答声变快，剪辑从 1 秒一刀变成 0.5 秒一刀 |
| 31.6–53.6 | 恐惧，卡在配乐的半秒网格上剪：窗户一扇扇亮起、光球越来越多、皮拉内西式的门厅、受惊的镇民、门闩被狠狠插上、每扇铁窗后都站着守望的人、锁孔里的眼睛、圆形监狱。最后 6.5 秒是 0.5 秒再到 0.25 秒一刀的快剪，晃动和闪烁越来越强 |
| 53.6–55.2 | 黑场。配乐最后一下下拍上落一记带混响的重击 |
| 55.2–65.2 | 黄金时刻，一个提灯的人走上山坡；山上孤零零的房子亮起一盏灯 |
| 65.2–82 | 答案，一个能力一个画面：像记忆地图的星图、一扇扇打开的门、机械手拨动开关、天文钟亮起、一只手敲门 |
| 82–92 | 前面的画面回来了，这次温暖明亮：公寓的窗、光球、单独的光球、空屋变成了有人住的书房 |
| 92–98.6 | 回应锁链：一双手扣上皮挽具，光球在后面亮着；最后一个词说完半秒后淡到黑 |

## 画面配方

- **两个风格前缀，每条 prompt 都加**（全文见 `prompts/shots.md`）：
  - 铜版画：钢版雕刻、交叉排线和点刻、满版裁切、不要纸边、不要边框、不要文字；
  - 胶片：70 年代 16mm Ektachrome 的一帧，颗粒、光晕，不要齿孔、不要日期戳、不要任何字母和数字。
- **一个反复出现的角色**：光球在每条 prompt 里都用同一句话描述，看起来才是同一个存在。
- **静帧**：Nano Banana Pro，4:3，2K。**片段**：用静帧做 MiniMax H3 Max 图生视频，6 秒，768P，运动单独写一条 prompt。
- **渲染器**（`template/tools/render.py`，Python + numpy + Pillow）：
  - 铜版画上双色调（每段一组暗部和亮部颜色：绿、棕褐、青、红、蓝）；
  - 胶片做调色（饱和度、RGB 增益、黑位抬升），有自己的几种色调（琥珀、夜、黄昏、金色）；
  - 两者都加颗粒、片门晃动、闪烁、光晕、灰尘和圆角 4:3 画框；
  - 带纸边的铜版画裁到版面（`PLATES` 集合），满版的不裁。
- **运动**：静帧慢推慢移；恐惧段加晃动和闪烁，随剪辑变快而加强。
- **结尾**：像电影一样收。最后一个故事画面淡到黑，黑一拍（不到一秒），然后 logo 单独在黑底上淡入、淡出（约 3.5 秒）。不要 slogan 字卡，也不要只为了给文字留位置而构图的收尾镜头。

## 声音配方

- **旁白**：ElevenLabs v4，Laura 的声音，整篇稿子一条生成，每段开头加情绪标签（`[softly, with wonder]`、`[wearily]`、`[tense]`、`[anxious, faster]`、`[whispers]`、`[warm, hopeful]`、`[gently]`）。生成三条，按情绪反差挑。在词与词之间最安静的地方切句，按词级时间戳放到位置上。
- **配乐**：ElevenLabs Music v2.5，**每幕一段**（共三段），各自单独生成。每条 prompt 都写明不要的乐器（吉他、民谣、合唱、人声）。
- **避让**：平静段落里音乐在人声下压 4 dB，恐惧段压 8 dB，并在她说话时挖掉 1–4 kHz。
- **每个段落交界都有重音**：进恐惧段前一个上扬音效加一个超低频轰鸣；恐惧段配乐自己的最后一下下拍上落一记重击，混响拖进黑场；之后是真正的静音。
- **动作声**（门闩、敲门、开门、钟的滴答）落在动作发生的那一帧。滴答声跟着日常段的剪辑走：一秒一下，再两下，再四下。
- **底噪**：全片铺一层 16mm 放映机的循环声，黑场时完全撤掉。
- **响度**：约 −15 LUFS，真峰值低于 −1.5 dB，响度范围约 9 LU。

## 流程

见 `template/`。生成之后的每一步都是代码，重建时不调用任何模型。

1. `shots.py`：风格前缀，以及每个镜头的 prompt 和运动描述。
2. `tools/stills.py`、`tools/vids.py`、`tools/music3.py`、`tools/vo2.py`：通过 CoreSpeed MCP 接口（`tools/cs_mcp.py`）生成素材。
3. `tools/beats.py`、`tools/onsets.py`：找出每段配乐的拍点网格和强起音，用来定剪辑点。
4. `timeline_v2.py`：剪辑表（镜头、色调、运动）、配乐位置、旁白句子、音效时间。
5. `tools/mix_v2.py`：混音和字幕时间。`tools/render.py`：画面，固定分 16 块渲染。
6. `build.sh`：检查版本和素材校验和，混音、渲染、编码，并把流哈希和交付的成片对比。
