# 伪录屏电影风（screen-life · singularity）

参考片：TakayamaMaria《我瘫坐在奇点，仿佛看见宇宙大爆炸爆炸》，B 站 BV17eHc6sEcX（3:15）。
本作：SINGULARITY（续集），2:52，4K，片子讲的是“从三十二元数到六十四元数失去了什么”。

## 关键词

- **形式**：伪录屏（screen-life）、贴屏微距、浅景深、斜角透视镜头、手持微抖、硬切
- **质感**：LCD 子像素特写、仿真界面（Windows / Chrome / Claude）、拼音输入法逐字打字、计数器跳动、终端数据流、窗口墙
- **叙事**：深夜时钟作时间锚点 → 人的问题搜不到 → 召唤 AI → 授权弹窗 → AI 接管、疯狂检索 → 记事本写下“现有文献没有给出答案 → 由我来证明” → 计算出发现 → 时钟到 0:00、静默一拍、重击 → 标题 → 流式答案
- **灵魂**：**内容是真的**。片中的发现必须真实可验证，终端输出要抄真实计算结果，不能声称完成了没完成的证明。

## 情绪（最容易定错）

- **主角是那个人，不是 AI。** 这是一个人眼看着远超自己的东西发生，最后瘫坐在椅子上的故事。
- **基调是“敬畏 + 不安”，不是“攻克难题、庆功”。** 后者会变成科技宣传片，这是第一版配乐踩的坑。
- 分段情绪：

| 段落 | 情绪 | 配乐方向 |
|---|---|---|
| 深夜开场 | 冷、空、孤独 | 低频嗡鸣，零星的远处钢琴 |
| 搜索无果 | 卡住、焦躁 | 同上，几乎不动 |
| AI 接管 | 不安、有东西醒了 | 不协和的弦乐慢慢爬升 |
| 由我来证明 | 屏息 | 几乎静默，只留一根高音泛音 |
| 计算 | 冷酷、机械、非人 | 小调机械固定音型，**绝不英雄化** |
| 发现、谱分裂 | 敬畏混着恐惧 | 合唱般铺底加低音铜管涨起 |
| 午夜 | 静默一拍 | 全部切掉，只剩钟表滴答，0:00 停止 |
| 标题 | 宇宙级的压迫感 | 一声巨大低频轰鸣，然后真空 |
| 回答 | 安静、脆弱、余味 | 孤零零的钢琴，停在不解决的和弦上 |

## 分镜语法（约 170 秒）

| 时间 | 镜头 |

| 0–4.6 | 真人：深夜雨窗，人在笔记本前打字，桌上闹钟 23:57 |
| 4.6–9 | LCD 子像素时钟特写 → 稍宽的时钟、日期 |
| 9–34 | 浏览器搜索：拼音输入法逐字打字、搜索结果页、维基百科“尚无可靠来源”、加引号再搜 → “找不到” |
| 34–49 | 任务栏点开 Claude → 模型下拉菜单选“Singularity 研究预览”（特写徽章）→ 输入问题 |
| 49–55 | 系统授权弹窗（远景 → “是”按钮特写，点击） |
| 55–66 | Chrome 被自动化控制，标签页一个个弹出 → 16 个窗口的窗口墙，镜头拉远 |

| 114–122 | 本征值分裂可视化（真实数据，一行一行展开） |
| 122–125 | 时钟 23:59 → 0:00，滴答声停止，静默约 0.35 秒 |
| 125–130 | 标题：黑色深空，一点光迸开成事件视界光环，下方是细体宽字距的 SINGULARITY |
| 130–133 | 真人：闹钟 0:00，窗外烟花，人瘫坐在椅子上 |
| 133–163 | Claude 流式答案，镜头跟随文字 |
| 163–171 | 片尾字卡：数学是真的、致敬原作 |

## 画面配方

- **镜头**：每个镜头写首尾关键帧（焦点、缩放、rotateX/rotateY），缓动插值，再叠一点手持噪声；镜头之间硬切，切入时做 0.2–0.5 秒的对焦拉清。
- **景深**：ffmpeg 里把模糊层按蒙版和清晰层混合（gblur + maskedmerge），中间一条水平带保持清晰。
- **质感**：泛光（高光模糊后用 screen 模式叠回）、轻微色差（rgbashift）、暗角、动态颗粒。
- **LCD 子像素**：把文字画在小画布上，再把每个像素放大成 R、G、B 三根竖条。
- **真人镜头**：Nano Banana Pro 出首帧，用编辑模式在首帧上改出尾帧（保证同一场景），MiniMax H3 Max 做首尾帧图生视频。

## 声音配方

- **键盘**：真实 MacBook 打字录音切成单次按键（这次切出 336 个），每次按键随机取一个。**人打字用真实按键声，AI 打字用更轻的数字按键声**，两者能听出区别。
- **底噪**：全片铺一层深夜公寓的房间环境声（远处车流、电器嗡声）。
- **关键时刻**：AI 接管用低沉的呼啸加闷响（**不要尖锐的电子扫频**）；“由我来证明”用低沉的鼓；午夜前合唱上升音推高，然后硬切静默；标题用低频轰鸣。
- **配乐**：用 AI 按分镜分段生成，每段指定时长和风格，第一段带一首对味的参考曲（这次用的是 Scott Buckley《Decoherence》），后面各段设成紧跟上下文；生成后再用分段音量自动化修正。
- **声画同步**：画面和音效出自同一份时间轴，每一下按键声都对应画面里的那一次按键。

## 技术管线

见 `template/`：
1. `film/`：HTML 页面里实现 `FILM.seek(t)`，画面是时间的纯函数，不用 CSS 动画。
2. `film/render.js`：puppeteer-core 多进程逐帧截图（`SCALE=2` 出 4K），也支持只重渲某一段帧。
3. `post.sh` / `post4k.sh`：后期、叠真人镜头、混入音轨、编码。
4. `audio6.py`：读取时间轴事件，放置音效、铺底、配乐分段音量，输出混音。
5. `math/`：数学验证（python-flint 精确计算）。

## 成本参考

- 第一版（1080p，合成音效）约 30 分钟。
- 媒体生成合计约 6,300 积分：两版配乐约 5,200（每版约 2,600），2 张关键帧、2 段图生视频、5 个定制音效合计约 1,100。
- 4K 渲染：8 核服务器 6 个进程约 30 分钟，后期编码约 25 分钟。
